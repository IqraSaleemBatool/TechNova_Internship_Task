# TechNova Internship – Task 03: Financial KPI Dashboard

##  Project Overview

This project was completed as **Task 03 of the TechNova Data Analytics Internship Program**.

The objective of this task was to analyze a business dataset, define key performance indicators (KPIs), and build a dashboard to provide a clear overview of financial performance.

The project uses the **Financial Sample dataset** and includes data cleaning, KPI calculation, exploratory analysis, visualizations, and dashboard development using Python.

An additional **Power BI dashboard** was also created to provide an interactive business reporting experience.

---

##  Objectives

- Analyze financial business data
- Clean and prepare the dataset
- Define and calculate key performance indicators
- Identify financial trends and patterns
- Create meaningful visualizations
- Build an interactive dashboard using Plotly Dash
- Create an additional Power BI dashboard for financial reporting


##  KPIs

- Total Sales
- Total Profit
- Total COGS
- Profit Margin
- Total Units Sold

##  Dashboard

The project includes:

- Python-based data analysis and visualization
- Interactive **Plotly Dash** dashboard
- Additional **Power BI** dashboard with interactive filters and financial visualizations
